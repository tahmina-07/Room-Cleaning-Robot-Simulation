## 🧹 Room Cleaning Robot Simulation

This project simulates a room cleaning robot that automatically navigates and cleans a virtual environment. It demonstrates fundamental programming concepts such as loops, conditional logic, object-oriented design, and simulation modeling.

## 🚀 Features

Simulates a robot moving within a 2D grid-based room

Tracks cleaned and uncleaned areas

Avoids obstacles and walls

Reports cleaning progress and total area cleaned

Customizable room size and starting position

## 💡 Technologies Used

Language: Python

Libraries: random, time, matplotlib (for optional visualization)

## 🧠 Learning Objectives

This project helps practice:

Algorithm design and simulation logic

Object-oriented programming (OOP) concepts

Working with loops and conditionals

Debugging and testing simple simulations
